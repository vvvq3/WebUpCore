## Коротко
- **UpCore — «цифровой тимлид»** от ИТ-компании Dex (основатель Иван Гель). Анализирует код (MR) по 50+ факторам,
  переводит его в реально затраченные человеко-часы → эффективность, грейд, рейтинг, деньги. Без отчётов и тайм-трекеров.
- **Формулировка про ИИ:** «ядро — детерминированная математика, поверх — ИИ-агенты для ревью и наставничества».
- **Ключевые цифры:** точность **«96% от экспертной оценки»** на более чем 300 тыс. MR (НЕ 85% — старая цифра; подкреплять методологией), посчитано **более 1500 разработчиков**, 50+ факторов,
  +14% эффективности за 3 месяца, +12% от прозрачности.
- **Платформа + 4 суб-продукта:**
  1. **UpCore Grade** — рейтинг эффективности и грейд-уровень по анализу MR (CTO, HRD, тимлиды)
  2. **UpCore AI** — эффективность ИИ / вайбкодеров: авто-детект ИИ-кода (есть) + промпт-коллектор (агент на машине разработчика)
  3. **UpCore Projects** — эффективность проектов, контроль подрядчиков (как BlueOptima), разовый аудит с расчётом бюджета проекта по коду
  4. **UpCore Mentor** — ИИ-наставник: где низкая эффективность + рекомендации (по задачам, промптам, коду)
- **Цель продукта — SaaS:** вход через GitHub/GitLab → подключение репозитория → оценки по каждому направлению.
  Цены не решены — конкретные тарифы на сайте не публиковать без согласования.
- **Сайт:** главная + страницы `/grade`, `/ai`, `/projects`, `/mentor` + блог (на старте топ-10 постов Telegram), FAQ, О компании, Безопасность, Политика конфиденциальности.

## ⭐ Грейд, отчёты и рейтинг — принципы владельца (раздел 22 базы знаний, применять на КАЖДОЙ странице)
- Грейд = сложная математика по **50+ факторам** (в звезде меню «Уровень» — 10 основных), **главный фактор — эффективность кода в часах**.
- **Полная прозрачность:** не только «Middle+, 7,8 из 10», но и все факторы грейда; каждый раскрывается в «Отчётах» **до строчки кода**.
- Яркие факторы: **архитектура по AST** (20 строк в ядре ценнее 200 на периферии), **технологии по картам компетенций** (часы, легаси/новое/«ввёл в проект»),
  **результирующий код** (300 строк → до релиза 50%; важно с ИИ, против накруток).
- **Эффективность — каждый месяц** (детальный отчёт), **грейд — за 3 месяца**, **рейтинг — каждый месяц** (компания/стек/проект, топ- и лоу-20%, сравнение со средним по команде/стеку/компании), динамика на графиках.
- **Всё автоматически — нужен только код.** Интеграции с системами клиента и по **MCP**.
- Тезисы-преимущества старого сайта (раздел 22.6): безопасность (on-premise без интернета), высокая точность (без человеческого фактора), простая интеграция (нужен только код, год кода — за минуты, любой язык), полная прозрачность («Глаз»), без «токсичного контроля» (обычное код-ревью, ~1 с на MR), исключаем накрутки.
