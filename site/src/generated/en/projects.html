FAQ

Honest answers to tough questions

What if the vendor won’t grant access to the code?

Contracts usually give the client ownership of the code. The analysis can run on-premise, fully inside your perimeter, with no internet access.

Does it work for 1C and legacy?

Yes: C#, Java, Go, Python, Kotlin, PHP, JS/TS, C++ and 1C. The share of legacy and its complexity are taken into account.

Will this replace work acceptance?

No — it gives acceptance an objective basis: how much effort is in the code vs. on the invoice.

Can a project be assessed when acquiring a company?

Yes. A one-off audit shows what the code cost, how much tech debt it carries and how well the team fits the stack.
