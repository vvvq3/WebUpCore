FAQ

Honest answers to tough questions

Can it work without the prompt collector?

Yes. The collector is optional. From code alone, UpCore detects AI-written code with over 92% accuracy on a month of work, and on three months for the grade.

Isn’t this prompt surveillance?

Prompts are reviewed for coaching: where context gets lost and how to get results faster. Access is role-based, and on-premise everything stays in-house.

How do you calculate efficiency with AI?

The model knows how long a task would take manually and compares it with the actual time spent with AI — for every MR, without trackers or reports.

Do we need to wait for data to accumulate?

No. Six months of history is already in your Git — UpCore analyzes it in an hour and shows the before-and-after picture right away.
