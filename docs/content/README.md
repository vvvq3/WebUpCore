## Что убрано из старых текстов (слабее или устарело)

- «Простота и доступность», «Гибкие настройки и самообучаемость», «Высокая точность (исключение человеческого фактора)» —
  общие слова без доказательства; смысл ушёл в конкретные тезисы (ответ на простом языке, 96%, «Глаз»).
- «Будущее UpCore» как отдельный блок — агенты теперь часть продукта Mentor, а не «планы».
- Цена «3 тыс. ₽», «−0,5% от ЗП», ROI 9,7 млн ₽ — не показаны (цены не согласованы); тезисы оставлены в таблице.
- «85%» — заменено на 96% (решение владельца).
