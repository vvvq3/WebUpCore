# Анимации сайта UpCore — утверждено (раунд 67, 14.11.2026)

Выбор владельца: **вариант 1 «Спокойная точность» как основа + 3 фирменных акцента из варианта 2 «Цифровой тимлид за работой»**.
Эталон с живыми демонстрациями — доска `Anim-final` на странице холста «Дизайн главной»
(https://claude.ai/artifact/57F1KYxREb3qKCN4yMdioJ), исходник — `anim_final()` в `tools/content/build_pages.py`.

Цель: сайт выглядит дорого и спокойно для C-level крупных компаний, разработчики видят «инженерный» почерк. Анимаций мало, каждая — по делу.

## Общие правила
- Каждая анимация проигрывается **один раз**, при первом появлении блока в экране (IntersectionObserver, порог ~20%), повторно не запускается.
- Длительность **200–800 мс**, кривая `cubic-bezier(.2,.7,.2,1)` (быстрый старт, мягкое замедление); для счётчиков — `cubic-bezier(.16,1,.3,1)`.
- Ничего не крутится постоянно (исключение — мигающий курсор в «разборе кода»).
- `prefers-reduced-motion: reduce` → все анимации выключены, контент показывается сразу.
- Анимируются только `transform`, `opacity`, `clip-path`, `filter` — без перерисовки макета; никаких библиотек тяжелее ~5 КБ (своя мини-утилита на IntersectionObserver).
- На телефоне всё, что привязано к курсору (наведение, подсветка), отключено; проявление и счётчики остаются.

## Раунд 76 — слайдер скриншотов
- Внизу окна ничего нет (ни подписи, ни кнопок, ни паузы): верхняя строка «upcore://screens / <экран>  NN / MM» + скриншот.
- Экраны сменяют друг друга без пауз (раунд 77): полоса проходит сверху вниз за **1,5 с** с постоянной скоростью («рисует» новый экран поверх старого) и сразу начинает сверху со следующим экраном.
- Пауза (полоса доходит до низа и останавливается): при наведении мыши (чтобы рассмотреть экран), когда окно вне экрана, когда вкладка скрыта; при «уменьшить движение» — без анимации и автосмены.
- Раунд 78: 14 скриншотов владельца (папка UpCoreScreen), окно 2:1; в верхней строке «upcore://screens / <экран>  NN / 14».
