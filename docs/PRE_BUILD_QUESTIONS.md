# Вопросы владельцу перед вёрсткой (раунд 68, 14.11.2026)

Уже решено (не спрашиваем повторно): Astro + TypeScript + Tailwind, автодеплой из GitHub Actions, хостинг в РФ (152-ФЗ), домен up-core.ru вместо старого сайта,
RU + EN, заявки на office@dex-it.ru, «Подключить» → https://demo.up-core.ru/, тёмная тема, реальные имена из демо разрешены, цены не публикуем,
блог — топ-10 постов канала, страницы FAQ / О компании / Безопасность / Политика нужны, все дизайны, меню и анимации утверждены.

У каждого вопроса — вариант по умолчанию: если ответ «по умолчанию», делаю так.

## А. Блокирует запуск
1. **Хостинг.** Какой провайдер в РФ и на чьё юрлицо? По умолчанию — Yandex Cloud (Object Storage + CDN + функция для формы). Нужен доступ (или создам инструкцию для вас).
2. **Домен up-core.ru.** У кого регистратор/DNS, кто переключит записи? Старый сайт — просто заменяем (по умолчанию) или сохранить копию на поддомене?
3. **Юрлицо для подвала и политики конфиденциальности:** полное название (ООО «…»), ИНН, ОГРН, адрес. Оператор персональных данных тот же? Уведомление в Роскомнадзор подано?
4. **«Провести демо».** По умолчанию — короткая форма на сайте во всплывающем окне: имя, компания, должность, телефон или Telegram, размер команды, комментарий + согласие на обработку ПДн → письмо на office@dex-it.ru и дубль в Telegram-бот. Нужна ли CRM (Битрикс24 / amoCRM)?
5. **«Получить демо-отчёт» и «Заказать аудит»** — та же форма с другой темой (по умолчанию) или отдельные сценарии?
6. **Сроки.** К какой дате нужен запуск? По умолчанию: сначала тестовый адрес (например, new.up-core.ru) для вашей проверки, потом переключение домена.

## Технические решения, которые принимаю сам (если нет возражений)
- Шрифты Bricolage Grotesque, Onest, JetBrains Mono — с нашего сервера (не Google Fonts): быстрее и без передачи данных за рубеж.
- Браузеры: последние 2 версии Chrome, Safari (iOS/macOS), Firefox, Edge, Яндекс.Браузер; телефоны от 360 px.
- Скорость: цель Lighthouse 95+; картинки в WebP/AVIF; JS — только меню, формы, анимации.
- Доступность: контраст по WCAG AA, навигация с клавиатуры, «уменьшить движение».
- OG-картинки для превью ссылок в Telegram/соцсетях — в стиле бренда для каждой страницы.
- Favicon, 404-страница, sitemap.xml, robots.txt, канонические ссылки, hreflang RU/EN.
