# Версия release1 — 18.11.2026

Первая версия сайта UpCore, готовая к выкладке на боевой хостинг. Git: ветка **`release1`** (тег можно добавить на GitHub: Releases → Draft a new release → тег `release1`, цель — ветка `release1`).
Показ: https://vvvq3.github.io/WebUpCore/ · Развёртывание — `docs/DEPLOY.md` · Устройство и правка — `docs/ARCHITECTURE.md`.

## Что входит
- **Главная** — новая версия по ТЗ владельца (8 секций → 5 экранов): первый экран «Цифровой тимлид **автоматически оценивает эффективность** вашей разработки» + 4 цифры и слайдер из 14 скриншотов демо; «Платформа UpCore» (4 продукта: факт + 3 пункта); «Как работает математическая модель» (160 ч → 80 из 160) + 4 карточки; «Экономический эффект» (≈6,5 млн ₽ / мес на 100 разработчиков); «Подключение за минуты»; синий блок «Проведите бесплатный пилот на 2–3 репозиториях».
- **Grade, AI, Projects, Mentor** — новые версии по ТЗ-2 с правками владельца (раунды 86–87).
- **Блог** — 3 страницы с фильтром по темам, посты ведут в @upcore_ai.
- **Единые для всех страниц:** шапка «Провести демо» + «Открыть демо» (обе — форма «Провести демо»), блок «Подключение за минуты», синий блок «Заказать бесплатный пилот» + «Открыть демо-стенд», подвал.
- **Форма заявки** (темы: демо, пример отчёта, аудит, бесплатный пилот; поля: имя, компания, размер команды, контакт). На GitHub Pages — письмо на office@dex-it.ru через FormSubmit; для боевого хостинга — `site/deploy/form-handler.php` (почта + Telegram). Запасной вариант — письмо с заполненной заявкой.
- **Анимации** (спокойные: появление блоков, цифры-табло, шкалы, слайдер-«сканер», блок 160 → 80, ховер всех кнопок), адаптив 360–1920 px, мобильное меню на весь экран (внизу телефон и Telegram).
- **SEO:** canonical, hreflang, Open Graph, sitemap, robots.txt, JSON-LD (Organization, SoftwareApplication, FAQPage, BreadcrumbList).
- Без переключателя языков. EN-страницы (`/en/…`) — прежние тексты, до запуска решить: перевести или убрать (см. `docs/DEPLOY.md`, раздел 10).
